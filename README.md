# 霍利屹的前端网页作品集

按用户提供的视频成品截图制作的单页作品集：深色背景、居中标题、红色圆点和三张作品卡片。卡片中的画面由三个作品的本地副本显示，点击卡片会打开对应的在线页面。

在 VS Code 中打开这个文件夹，直接用浏览器打开 `index.html` 即可预览；使用 Live Server 也可以。页面不需要安装依赖。

| 作品 | 在线页面 | 源码 |
| --- | --- | --- |
| Quiz Time | https://web2-drab-delta.vercel.app/ | https://github.com/shigaharuki17/web2 |
| Register Form | https://shigaharuki17.github.io/web1/ | https://github.com/shigaharuki17/web1 |
| Recipe Finder | https://web3-flame-three.vercel.app/ | https://github.com/shigaharuki17/web3 |

`previews/` 只用于作品卡片内的预览，修改作品集布局请编辑根目录的 `index.html` 和 `styles.css`。视觉规则记录在 `design.md`。
